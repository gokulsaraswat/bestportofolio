# ADR-001: Use Spring Boot for Microservices

## Context
We need a framework that supports rapid
microservice development with strong
ecosystem support.

## Decision
Adopt Spring Boot 2.7 with Java 17.

## Consequences
- Mature dependency injection
- Excellent observability integrations
- Large talent pool
