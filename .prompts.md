# Prompt Playbook — CLAUDE.md Workflow

## 1. Starting a New Folder / Project

**Use Case:** Bootstrapping a project from scratch and need the AI to establish the foundation and populate the initial architecture files.

> I am bootstrapping a new project. Attached are `CLAUDE.md` and the blank `.claude-session.template.json` (rename to `.claude-session.json` once populated).
> Goal: Create a [Insert Tech Stack, e.g., Next.js 14 + Tailwind] application that does [Insert Core Function].
> Instructions:
> - Actively adopt the persona in `CLAUDE.md`.
> - Give me the initial terminal commands to generate the project skeleton.
> - Provide the initial populated state for `.claude-session.json` defining our Day 1 sprint goal.
> - Do not write any business logic yet; focus strictly on configuring the base directory topology.

## 2. Starting with an Existing Project

**Use Case:** You just ran `sync-architecture.sh` on an existing codebase and are passing the context files into a fresh chat.

> Attached are `CLAUDE.md`, `.project-architecture.md` (generated by the sync script), and the current `.claude-session.json`.
> Goal: I want to implement [Insert Feature] / fix [Insert Bug].
> Instructions: Review the HLD/LLD mappings. Identify which specific domain files or interfaces will be impacted by this change. Based on our strict Anti-Hallucination protocol, output exactly which class headers, file snippets, or database schemas you need me to paste here before you can formulate a SOLID-compliant solution.

## 3. The "After-Command" Chaser

**Use Case:** Append this short phrase to the end of your standard prompts to force the AI to continuously update you on its state and prevent context drift.

> ... [Your specific task instructions].
> Post-Task Execution: Provide the exact SEARCH/REPLACE blocks for the code. Do not explain the code. Finally, output a 3-bullet-point summary of any structural changes we just made so I can add them to `.project-architecture.manual.md` (create this file if it doesn't exist yet — `sync-architecture.sh` preserves it across regenerations).

## 4. Start / Debug Prompt Template

> Here is the architectural footprint of my system (attached `CLAUDE.md`, `.project-architecture.md`, and `.claude-session.json`).
> Goal: I need to design a feature / fix a bug where [Insert Context].
> Instructions: Analyze this based on our HLD/LLD principles inside `CLAUDE.md`. Propose the LLD interface shifts or structural changes needed before writing any code. Tell me exactly which specific lines of code or class headers you need to inspect. Do not write the full implementation yet.

## 5. Session Wrap-Up Prompt Template

> We are wrapping up this engineering session. Give me the updated JSON block for the `sprint` field inside `.claude-session.json` and any Mermaid graph updates for `.project-architecture.md` based on what we resolved today.

## 6. The Context Recovery Prompt (Anti-Hallucination Trigger)

**Use Case:** Use this if the AI starts guessing variable names or writing generic boilerplate.

> HALT. You are hallucinating implementations. Review Rule 3 (Anti-Hallucination Protocol) in `CLAUDE.md`. Discard your previous response. Output only the `[REQ_CONTEXT]` tags for the exact interfaces or file pathways you are missing to complete this task accurately.
